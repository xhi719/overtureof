# KSCO 제8차 한국어 항목표

## 출처와 범위

- 국가데이터처(당시 통계청)의 [제8차 한국표준직업분류 개정·고시](https://mods.go.kr/board.es?act=view&bid=107&list_no=431582&mid=a10403040000), 통계청 고시 제2024-328호, 2024-07-01, 2025-01-01 시행. 원본은 해당 페이지의 `제8차 한국표준직업분류 개정 분류 항목표.hwpx`입니다.
- 고시된 한국어 코드·명칭을 저장합니다. 1,999개는 고유한 직업명 1,999개라는 뜻이 아니라 대·중·소·세·세세분류 항목의 합계입니다. 단계별 건수는 10 / 57 / 167 / 495 / 1,270개입니다. 분류 코드 A(군인)는 보존합니다.
- [질병관리청 자동신고 분류표 v1.2](https://dportal.kdca.go.kr/pot/bbs/BD_selectBbs.do?q_bbsDocNo=20231228181112365&q_bbsSn=1021&q_clsfNo=-1)는 코드 집합 대조에만 사용했습니다. 감염병 신고를 위한 추가 코드 W, X, Y는 고시 분류가 아니므로 포함하지 않습니다. 영어 번역은 수록하지 않습니다.
- 질병관리청 자료와 통계청 고시의 코드 집합은 일치하나, 13개 표기의 차이가 확인되었습니다. `43199`, `4321`, `77190`은 어휘 또는 철자 차이가 있어 통계청 고시 원문을 기준으로 했습니다. 나머지 차이에는 공백과 문장부호가 포함됩니다.

## 이용과 재현

국가데이터처 고시문은 이 분류 항목표가 고시 범위에 포함된다고 명시합니다. [저작권법 제7조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033063839)는 국가 또는 지방자치단체의 고시를 보호받지 못하는 저작물로 규정합니다. 이 기록은 분류 항목표 자체의 출처와 검토 근거이며, 질병관리청 첨부물 전체나 영어 번역에 대한 자유이용 허락을 주장하지 않습니다. 질병관리청의 [저작권 정책](https://kdca.go.kr/kdca/3509/subview.do)은 공공누리가 없는 자료의 이용 전 담당자 협의를 안내합니다. 공개 배포 시 적용 범위와 다른 자료의 권리 상태를 별도로 확인해야 합니다.

원본 HWPX SHA-256: `9d344859fc201e23b2270bb5667fe77636708c08aa5957e800786e03705396a1`. 질병관리청 대조용 XLSX SHA-256: `b6070733df86cebdd195adb50b3a25a73a5fd8fb2036b4d18e69940dd30b674d`.


정규화는 원본 해시, 중복 코드, 공식 분류별 개수와 부모-자식 관계를 검사합니다. 가져오기는 정규화 파일 해시도 검사하고 기존 데이터가 고시 내용과 충돌하면 트랜잭션을 중단합니다. 기존 한국어 명칭을 무조건 덮어쓰지 않습니다. 원본 파일은 `data/raw/`의 로컬 검증용 파일이며 Git에서 제외됩니다. 중국어 명칭, 개별 업무 설명, 연구 수치 및 대체 확률은 이 자료에 포함되지 않습니다.
