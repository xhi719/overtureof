# 가정 기반 대체 시계 — 모델 5.0.0

이 결과는 **검증되지 않은 가상 시뮬레이션**입니다. 표시된 숫자와 날짜는 연구기관의 직업 대체 예측이나 실제 고용 감소 확률이 아닙니다. 진로·취업·투자 판단을 위한 자료로 검증되지 않았습니다. 기존 검증 예측 데이터와 별도로 계산합니다. 현재 설정은 [model-v5.json](../data/scenario/model-v5.json)에 있으며, 이전 [v4 설정](../data/scenario/model-v4.json)과 [v4 설명](scenario-model-v4-ko.md), [v3 설정](../data/scenario/model-v3.json)과 [v3 설명](scenario-model-v3-ko.md), [v2 설정](../data/scenario/model-v2.json)과 [v2 설명](scenario-model-v2-ko.md), [v1 설정](../data/scenario/model-v1.json)과 [v1 설명](scenario-model-v1-ko.md)도 보존합니다.

## 가상의 사건과 출발점

가상 사건은 AI 도입에 기인한 해당 직업의 고용 수요가 기준보다 **10% 이상 감소**하는 것입니다. 기준 순간은 이전 모델과 동일한 **2026-10-31 10:09:49 UTC**입니다. 시간 t는 이 순간으로부터 365.2425일을 1년으로 계산합니다. 이 모형은 특정 국가의 실제 고용 변화를 측정하지 않습니다.

연구값이 직접 있는 경우에는 승인된 [OpenAI·OpenResearch·펜실베이니아대 2023년 연구](https://openai.com/index/gpts-are-gpts/)의 해당 O*NET 직업 `human_rating_beta` 업무 노출 점수를 0~1의 원 입력으로 사용합니다. 이 자료는 LLM으로 업무 시간을 줄일 수 있는 잠재력 평가이며, 이 모델의 고용 감소 확률이나 시점을 제시·검증하지 않았습니다. 원본 값은 수정하지 않습니다.

## 직업명 기반 간접 추정

해당 직업에 직접 점수가 없으면 한국어 직업명의 문자 2~4그램 TF-IDF와 코사인 유사도를 이용해 점수가 있는 O*NET 직업 최대 5개의 노출 점수를 참조합니다. 유사도 자체가 공식 직업 분류 대응 관계나 같은 업무라는 증거는 아닙니다. 가중 평균에는 유사도의 4제곱을 사용하고, 최고 유사도 s에 따른 `q = clamp((s-0.15)/0.85, 0, 1)^2`로 아래와 같이 전체 학습자료 평균 쪽으로 강하게 수축합니다.

`이름기반 추정 = 전체 평균 + q × (유사 직업 가중 평균 - 전체 평균)`

최고 유사도가 0.15 미만인 경우 전체 평균을 공통 가정으로 사용합니다. 직접 자료·이름 기반 추정·공통 가정은 API와 방법 화면에서 구분합니다. 2023년 미국 연구의 입력과 한국 직업명 사이에는 지역·직무 구성 차이가 있고, O*NET 한국어 이름은 기계번역 초안이므로 유사도가 높아도 잘못 매칭될 수 있습니다.

원 자료가 승인되지 않거나 학습에 사용한 O*NET 직업명·점수·구성이 바뀌어 사전 계산 데이터와 맞지 않으면 이름 기반 추정을 쓰지 않고 공통 가정 0.5로 전환합니다. 대상 직업명만 바뀐 경우에도 그 직업은 공통 가정으로 전환합니다. 직업을 추가하면 다음 사전 계산 전까지 공통 가정이 적용됩니다. 학습용 원자료·번역·제외 목록을 바꾼 후 `python etl/build_scenario_name_proxy.py`로 아티팩트를 다시 생성해야 합니다. 이 작업에는 numpy, scipy, scikit-learn이 필요하며 생성 파일에 라이브러리 버전과 입력 파일 해시가 기록됩니다.

2026-10-31 산출 데이터에서 이름 중복을 같은 그룹으로 묶어 447개 학습·112개 보류한 단일 분할의 노출도 점수 평균 절대오차는 0.152, 학습 평균만 사용한 기준은 0.178입니다. 이는 **과거 노출도 입력값을 이름으로 근사하는 실험**일 뿐, 직업별 대체 확률이나 발생 시각의 성능 검증이 아닙니다. 한국 직업에 대한 유효성도 입증하지 않습니다.

## 사용자 요청에 따른 가상 변동과 시간 중복 처리

직접 연구 점수가 없는 직업은 화면상 서로 다른 시계를 제공하기 위해 직업 분류·버전·코드를 SHA-256으로 해시한 후, 최대 **±0.03**의 인위적 변동을 입력 점수에 추가합니다. 이름 유사도에 따른 수축 강도가 높을수록 이 변동을 줄입니다. 예측의 근거나 실제 직업 차이를 반영하는 값이 아닙니다. 직접 연구값이 있는 직업에는 이 ±0.03 변동을 적용하지 않습니다. 원 입력 `exposure`, 적용된 `syntheticDelta`, 실제 수식에 들어간 `effectiveExposure`는 API에 구분해 제공합니다.

가상 변동을 적용한 뒤에도 목표 시각이 같은 초에 겹치면 분류·버전·코드 순서로 배정하며 비어 있는 초를 1초씩 찾습니다. 시간 순서를 유지할 수 없으면 반대 방향도 확인하고, 그 보정 시각에서 50%가 되도록 수식 입력을 극소 역산합니다. `adjustmentSeconds`가 이 별도 시간 보정입니다. 전체 직업 DB가 바뀌지 않으면 결과는 재현되지만, 같은 초에 충돌하는 직업이 추가·삭제되면 해당 충돌군의 초 배정은 달라질 수 있습니다. 표시 확률을 반올림하면 서로 다른 직업도 같은 숫자로 보일 수 있습니다.

## 수식과 타이머

사용자 요청에 따라 KSCO 8차 241 의사·한의사·치과의사 계열과 O*NET 31.0의 의사·외과의·치과의 공식 코드에 해당하는 항목에만 **추가 위험률 2배**를 적용합니다. 수의사, 간호사, 약사, 의사 보조원 및 광범위한 기타 진료 종사자는 해당하지 않습니다. 이 조정은 연구 결과가 아닌 사용자 요청에 따른 임의 가정입니다. 직접 연구 노출도의 3배 조건도 충족하면 3배와 2배를 곱한 6배를 적용하므로 v4보다 타이머가 약 절반이 됩니다(동점 보정 수초 제외). 이 의료 코드 목록은 [모델 설정](../data/scenario/model-v5.json)에 저장하며 제외된 직업을 복원하지 않습니다.

일괄 3배 가속한 v3을 중단하고 v2 계수를 기본으로 복구했습니다. 직접 연결된 O*NET 원문의 human_rating_beta 업무 노출도가 **0.5를 초과하는 경우에만** 가상 위험률을 3배 적용합니다. 연구가 업무 노출도 50% 초과 직업군을 분석한다는 점을 직업 선택 기준으로 참고했을 뿐, 3배 가속과 날짜는 사이트가 정한 임의 가정이며 연구에서 예측하거나 검증한 값이 아닙니다. 노출도 0.5 이하는 연구 기준 선택 가속을 하지 않습니다. 한국어 직업명 유사도와 공통 가정, 승인 철회된 자료로는 연구 기반 선택 가속을 적용하지 않습니다. 의료 코드 가속은 이와 별도로 적용됩니다. 적용 여부는 가상 보정 전 직접 연구값으로 판정합니다. 같은 입력의 연구 기준 가속 타이머는 의료 가속을 별도 적용하기 전 v2의 약 1/3입니다(충돌 보정 수초 제외). e는 위 가상 변동과 동점 보정 후 입력입니다.

- 연간 가상 위험률: `λ = m × (0.012 + 0.06 × e)`; `m = 연구 가속 계수 × 의료 가속 계수`: 직접 연구 노출도가 0.5 초과면 연구 계수 3, 그 외 1; 의료 직업 목록에 해당하면 의료 계수 2, 그 외 1
- 기준시각부터 t년까지 가상의 누적 확률: `P(t) = 1 - exp(-λt)`
- 타이머 목표: `P(t)=0.5`가 되는 `t = -ln(1-0.5)/λ`와 위 동점 보정
- 연도별 확률은 해당 연도 말까지이며, 다음 해 1월 1일 UTC 경계까지의 경과 시간을 사용

월·일·시각은 원문 연구가 제시한 날짜가 아니라 이 가정 모형과 동점 처리에서 계산한 내부 시점입니다. 경제·법률·신규 일자리·직무 변화·물리적 제약이나 실제 기술 도입률을 충분히 반영하지 않습니다.

## 캐시와 확인

매 요청마다 일관된 DB 스냅샷에서 전체 직업, 한국어 명칭, 승인된 원문 점수를 읽고 모델 설정과 사전 계산 아티팩트를 포함해 SHA-256으로 식별합니다. 완전히 같은 스냅샷일 때만 직전 계산 결과를 재사용합니다. 출처 승인·직업명·원문 점수·직업 추가/삭제·설정·아티팩트 변경은 즉시 캐시를 무효화합니다.

`npx tsx scripts/verify-scenario-coverage.ts`는 DB의 각 직업에 유효한 시뮬레이션이 있는지, 초 단위 타이머 중복이 없는지, 재현성과 50% 교차 수식을 확인합니다. 직접 연구값 임계치, 비대상 직업 및 출처 승인 철회 시 연구 가속 중단과 의사군 타이머 단축도 확인합니다. 이는 실제 예측의 정확성을 검증하는 절차가 아닙니다.
