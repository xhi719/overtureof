# overture of

AI 노출과 검증 가능한 예측을 구별해 보여주기 위한 Next.js / PostgreSQL 기반 프로토타입입니다. **운영 가능한 완성 서비스가 아닙니다.** 공식 직업 분류 일부를 로컬 데이터베이스에 적재했습니다. 화면의 수치와 시계는 실제 예측이 아닌 검증되지 않은 가정 기반 시뮬레이션입니다.

## 코드와 브랜드 자산의 공개 범위

이 프로젝트의 자체 코드는 [MIT 라이선스](LICENSE)를 따릅니다. 이 라이선스는 제3자 데이터·번역 원문·연구자료 또는 Frontier Era 로고와 상표에 대한 권리를 부여하거나 해당 자료의 별도 이용조건을 대체하지 않습니다. 제3자 자료는 각각의 출처·이용조건·변경 고지를 따릅니다. 공개 저장소에 올리면 GitHub의 이용약관에 따라 저장소를 열람하거나 포크할 수 있습니다.

Frontier Era 공식 로고 `public/images/frontier-era-logo.png`는 이 사이트에서 사용하도록 제공된 자산이며 공개 저장소의 기본 포함 대상에서 제외되어 있습니다. 해당 파일을 배포할 수 있는 권리를 별도로 확인한 경우에만 로컬의 해당 위치에 원본을 배치하세요. 파일이 없으면 워터마크는 표시되지 않습니다. 로고·상표에 대한 별도의 재사용 허락은 이 안내로 부여되지 않습니다.

공개 전 `python scripts/audit-github-release.py`로 현재 제외 규칙을 적용한 후보 파일의 일반적인 비밀정보 패턴과 민감 파일을 선별 검사할 수 있습니다. 이 검사는 모든 비밀정보를 찾거나 이미 추적된 파일·커밋 이력을 검사하지 않습니다. 저장소 생성 후 실제 스테이징 목록과 모든 공개 대상 이력을 별도로 검토하세요. `.gitignore`는 이미 추적된 파일이나 강제 추가를 막지 못합니다.

## 이 컴퓨터에서 실행

이 작업 공간에는 프로젝트 전용 PostgreSQL과 데이터가 `.runtime`에 준비되어 있으며 접속 설정은 `.env`에 저장되어 있습니다. 기존 `.env`를 덮어쓰지 마세요. 데이터베이스는 로컬 주소 `127.0.0.1:55432`에서만 수신합니다.

```powershell
cd D:\HEINT\frontier-era
npm run db:local:start
npm run dev -- --hostname 127.0.0.1 --port 3001
```

브라우저에서 `http://127.0.0.1:3001/ko`를 엽니다. 종료된 DB는 `npm run db:local:start`로 다시 시작합니다. `npm run db:local:stop`으로 이 프로젝트 DB를 중지할 수 있습니다. `.runtime`에는 DB 데이터가 포함되므로 삭제하지 마세요. 기존 포트 3000 서버가 이전 접속 설정을 사용하는 경우 새로 시작해야 합니다.

다른 환경에서는 Node.js와 PostgreSQL을 준비하고 `.env.example`의 `CHANGE_ME` 값을 자신의 개발 환경에 맞게 바꾼 별도의 `.env`를 사용합니다. Git에서 제외된 Anthropic 노동시장 자료가 없어도 타입 검사와 빌드는 가능하지만, 자료가 없거나 올바르지 않으면 시뮬레이션 결과 API는 503을 반환합니다. 기존 결과를 제공하려면 이용조건을 검토한 뒤 해당 원자료를 직접 확보하고 아래 순서대로 정규화해야 합니다. 이어서 `npm run db:push`, `npm run db:seed`와 아래 자료별 수입 명령을 실행합니다. 시드는 모든 직업·연구값을 자동으로 채우지 않습니다. `db:push`는 개발 환경용입니다. 운영 도입 전에는 검토된 마이그레이션과 백업이 필요합니다.

```powershell
Invoke-WebRequest -Uri 'https://huggingface.co/datasets/Anthropic/EconomicIndex/resolve/7a1cc3c/labor_market_impacts/job_exposure.csv' -OutFile 'data/anthropic-labor-2026/job_exposure.csv'
python etl/normalize_anthropic_labor.py
```

이 자료의 저장소 메타데이터와 본문 라이선스 표기가 달라 배포 조건과 CC-BY 버전은 별도 확인이 필요합니다. 위 정규화 명령은 기록된 SHA-256을 검사하지만 이용 허락이나 재배포 권리를 보장하지 않습니다. 새 환경에서 이 파일을 공개 저장소에 커밋하지 마세요. ISCO-08 원본·파생 파일도 재배포 권한 검토 전까지 Git에서 제외됩니다. 자세한 출처와 조건은 [데이터 및 공개 검토](docs/data-publication-review.md)에 있습니다.

정규화한 데이터를 설치하거나 교체한 후에는 서버를 재시작하세요. 연구 자료만으로 기존 로컬 데이터베이스의 전체 직업·시뮬레이션 구성이 자동으로 복원되지는 않습니다.

관리 화면은 `/ko/admin`입니다. `ADMIN_TOKEN`에 충분히 긴 무작위 값(최소 32자)을 지정하고 서버를 재시작해야 합니다. 토큰은 서버 환경변수에만 보관하고 화면에서 입력하며 브라우저 저장소에 저장하지 않습니다. 현재 단일 토큰 방식은 개발용 기초 인증이며 운영에 필요한 계정별 권한, 인증 세션, 비밀번호 정책, 잠금 및 보안 운영을 제공하지 않습니다. 외부에 공개하기 전에 별도 보안 설계가 필요합니다.

## 구현 상태

- 어두운 지도 인트로와 스크롤 검색, 고정폭 숫자 타이머, 반응형 레이아웃 및 모션 감소 지원. [지도 데이터 출처](docs/natural-earth-map.md).
- 4개 언어의 외부 콘텐츠와 DB 콘텐츠 덮어쓰기, 검색·페이지네이션·상세, 검증되지 않은 가정 기반 확률과 카운트다운. 방법 화면과 API에서 연구 입력, 직업명 기반 추정 및 공통 가정을 구분합니다. v10은 v8의 가상 확률에 v9 타이머 재가중을 결합해 일관된 확률을 계산합니다. 연구기관이 제시한 대체 확률이나 시점이 아닙니다. [v10 계산 방식](docs/scenario-probability-v10.md).
- 직업 검색은 동일 표기와 공식 하위 분류가 확인된 복합 상위 항목을 정리하고, 공식 코드가 하나인 복합 분류 123개는 검토된 구성 명칭 255개로 제공합니다. 이 명칭들은 기존 공식 분류의 결과를 공유하며, 아직 분리하지 못한 복합 분류가 있습니다. [분리 명칭과 재적재 방법](data/translation/occupation-components-README.md).
- 범용 15문항의 DB 시드, 기본적인 분기·진행률, 최대 5개 직업 비교. 개인 결과는 답변과 제공된 근거를 보여주며 검증되지 않은 개인 확률을 만들지 않습니다.
- 관리자 콘텐츠 수정 및 기존 연구 출처 승인/반려 API와 화면, 감사 로그의 기초. 다른 관리자 기능은 아직 구현되지 않았습니다.
- 선택적 연구 동의 및 응답 저장·삭제 경로. 검토·게시된 `research-consent` 법률 문서가 없으면 저장은 비활성화됩니다. 정책 문서는 게시 후 수정하지 말고 새 버전으로 관리해야 합니다. 이 코드는 적법성 검토를 대신하지 않습니다.
- 만료 응답 제거 스크립트 `npm run cleanup`이 제공됩니다. 보유기간이 실제로 지켜지려면 운영자가 적어도 매일 실행되도록 외부 스케줄러를 설정하고 실패를 감시해야 합니다. 스케줄러는 아직 구성되지 않았습니다.
- `etl/stage_classification.py`는 공식 파일을 검토 대기 자료로 검증합니다. KSCO와 O*NET은 각각 전용 적재 스크립트가 있습니다. 공식 자료 수집 스케줄 및 전체 보고서 검토 워크플로는 아직 구현되지 않았습니다.

## 데이터 및 연구 범위

- [한국표준직업분류 제8차](data/ksco8/README.md): 통계청 고시의 한국어 분류 항목 1,999개를 적재했습니다. 대·중·소·세·세세분류 단계의 합계이므로 서로 다른 직업 1,999개를 뜻하지 않습니다. 세세분류는 1,270개입니다. 동일 명칭의 상위·하위 분류는 검색에서 더 세부적인 항목만 표시합니다. 혼합 한국어 검색에서 KSCO와 O*NET의 표시명이 같으면 KSCO를 우선 표시하지만 원본과 직접 링크는 보존합니다.
- [O*NET 31.0](data/onet-31.0/ATTRIBUTION.md): 공식 원본 직업 1,016개 중 번역이 부정확한 414개를 제외하여 602개가 남아 있습니다. 현재 별칭과 일반 업무 11,290개가 연결돼 있습니다. 업무는 자동화 가능 여부가 아니라 원문의 일반 업무입니다. 남은 직업명 602개에는 한국어 기계 번역 초안이 있으며, 전수 전문 검토가 필요합니다. 원문 영어 검색은 유지됩니다. [번역 출처와 제한](data/translation/README.md)을 참고하세요. USDOL/ETA O*NET 데이터는 CC BY 4.0으로 제공되며 검색과 크레딧에 출처 및 변경 고지를 표시합니다.
- [ILO ISCO-08](data/isco-08/README.md): 원본의 단위집단 436개를 정규화해 검토용으로 보관했습니다. 공개 재사용 권한이 확인되지 않아 DB에는 넣지 않았습니다.
- [연구자료](data/research/README.md): ILO·OECD 보고서 5건은 검토 대기, OpenAI 보고서 1건은 업무 노출도 입력 목적으로 검토 승인됐습니다. 이 가운데 [OpenAI 2023 연구자료](data/openai-gpts-2023/README.md)의 업무 노출도 원본은 923개 직업에 대한 값 5,538개이며, 번역 오류로 직업을 제외한 현재 DB에는 540개 직업의 3,240개 값이 남아 있습니다. 연구자료의 노출도는 대체 확률이 아닙니다. 사이트는 사용자 승인에 따라 이를 임의 계수의 가상 모형 입력으로 사용하며, 현재 등록된 2,601개 분류 항목 중 540개는 직접 연결된 직업별 노출도, 1,958개는 한국어 직업명 유사도 기반 추정, 103개는 공통 가정을 사용합니다. 유사도 추정은 공식 직업 대응이나 검증된 예측이 아닙니다. 추정 및 공통 가정에는 직업 코드로 결정되는 인위적 변동을 더하며, 시각이 겹치면 초 단위로 추가 보정합니다. 이 차이는 연구가 확인한 차이가 아닙니다.

- [Anthropic 2026 업무 노출](data/anthropic-labor-2026/README.md): 미국 SOC 756개 직업군의 Claude 업무 사용 기반 관측 지표를 보존합니다. 현 O*NET 중 436개는 같은 SOC 직업, 99개는 상위 SOC 지표와 연결됩니다. 이는 고용 대체 확률이 아닙니다. 공개 재배포 조건 확인 전 원본 및 정규화 파일은 Git에서 제외됩니다.
- [Anthropic 2026 로봇 업무 노출](data/anthropic-robot-2026/README.md): O*NET 29.3의 업무 노출 0–3 지수를 O*NET 31.0의 동일 코드에 연결하며 버전 간 완전 대응을 가정하지 않습니다. 고용 대체 확률이나 실제 도입률이 아닙니다.
- [미국 노동통계국 2025–2035 고용 전망](data/bls-2025-2035/README.md): 공식 SOC 831개 행과 O*NET 대응표를 보존하고 현 O*NET 581개 항목에 상위 SOC 고용 전망을 연결합니다. 고용 전망은 AI의 영향만 따로 추정한 값이나 세부 직업의 별도 예측이 아닙니다.

검증된 예측은 0개입니다. 별도로 구현한 가상 시계는 연구기관이 제시한 예측이 아닙니다. 수식·기준시각·한계는 [시뮬레이션 모델 설명](docs/scenario-probability-v10.md)에 기록되어 있습니다. 공식 분류별 자료와 언어가 다르므로 그대로 합산해 전 세계 고유 직업 수로 표시하지 않습니다. 한국어 KSCO 직업 설명·업무 및 중국어 번역, 분류 간 대응 관계, 검증된 직업별 대체 확률은 아직 수록하지 않았습니다. 통계 모델 학습·시간순 검증·Brier 점수·보정 그래프·민감도 분석과 모델 재계산도 미구현입니다. 화면에 표시되는 대체 확률과 날짜는 검증되지 않은 모델 가정의 결과임을 명시합니다.

번역 오류로 제외한 코드와 사유는 [제외 목록](data/translation/onet-31.0-exclusions.json)에 기록했으며 재적재 시 자동 제외합니다. 삭제 전 전체 DB 백업은 로컬 `.runtime/backups/`에만 있으며 Git에 포함하지 않습니다. [예비 한국 법령 검토](docs/legal-review-ko.md)도 참고하세요. 현재 시뮬레이션 전수 검증은 `npx tsx scripts/verify-scenario-v10.ts`로 실행합니다. 재적재 및 검증 방법은 각 데이터 설명서를 참고하세요. KSCO와 O*NET을 수입한 뒤 `npx tsx scripts/sync-occupation-components.ts`로 검토된 분리 명칭을 동기화합니다. 일반 실행 시에는 이미 적재된 DB를 그대로 사용합니다.

```powershell
npm run typecheck

```

콘텐츠 검사는 JSX의 정적 표시 문구, 일부 정적 속성, CSS 고정 문구와 네 언어의 키 일치를 검사합니다. 모든 동적 표현·직업명·확률의 하드코딩, DB-화면 일치 및 번역 갱신을 완전하게 증명하는 검사는 아닙니다. 테스트는 예측 범위·단조성 및 설문 분기 등 제한된 단위 검사입니다. 로컬 DB에서 직업 검색, 상세 일반 업무, 15문항 조회를 확인했습니다. 연구 동의 저장/삭제와 관리자 변경은 통합 검증하지 않았습니다. 전체 모바일 크기, 키보드, WCAG 대비, 차트 및 카운트다운은 실데이터로 검증하지 않았습니다.
